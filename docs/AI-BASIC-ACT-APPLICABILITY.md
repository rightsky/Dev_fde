# AI 기본법 적용 여부 분석 (FDE Data Studio)

2026-10-17 기준. 대상 법령은 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」(법률 제20676호, 2025.1.21 공포, 2026.1.22 시행, 최근 개정 법률 제21311호 2026.1.20)과 같은 법 시행령(대통령령 제36053호, 최근 개정 제36580호 2026.8.20)이다. 법률 자문이 아니라 제품 설계 관점의 적용성 검토이며, 확정이 필요한 쟁점은 과기정통부 인공지능기본법 지원데스크(KOSA) 서면 질의를 권한다.

## 1. 결론 요약

| 질문 | 판단 | 근거 |
|---|---|---|
| 이 스튜디오를 운영하는 기관은 "인공지능사업자"인가 | 스튜디오 자체 운영에 관해서는 **해당하지 않을 여지가 크다** | 제2조제7호나목의 이용사업자는 AI 를 이용해 제품·서비스를 "제공"하는 자. 기관 직원만 쓰는 내부 도구이고, AI 초안은 담당자가 검수·확정해야 정본에 들어간다. 투명성 가이드라인(2026.1)도 AI 를 업무 도구로 쓰는 이용자는 의무 주체가 아니라고 본다 |
| 고영향 인공지능에 해당하는가 | **아니다** | 제2조제4호 가~차목 어느 영역도 아니다. 자목(공공서비스 자격 확인·결정·비용 징수)은 국민에게 영향을 미치는 의사결정에 한정되고, 메타데이터 작성·카탈로그 발행은 그 의사결정이 아니다 |
| 투명성 확보 의무(제31조)가 걸리는가 | **원칙적으로 면제**, 단 조건부 | 시행령 제23조제4항제2호 "사업자 내부 업무 용도로만 사용하는 경우" 적용 제외. 다만 AI 가 쓴 초안을 **대국민 포털에 그대로 게시**하면 제31조제2항(생성형 AI 결과물 표시)이 쟁점이 된다 |
| 안전성 확보 의무(제32조) | 해당 없음 | 누적 연산량 10^26 FLOPs 이상 모델의 학습 주체(Anthropic) 의무 |
| 국내대리인(제36조) | 해당 없음 | 해외 개발사업자 측 의무. 매출 1조·AI 매출 100억·일평균 이용자 100만 기준 |
| 과태료 위험 | 현재 **낮음** | 제43조 과태료는 사전 고지 미이행·국내대리인 미지정·시정명령 미이행 3가지뿐이고, 과기정통부가 최소 1년(2027.1.22 이전까지) 계도기간을 운영 중 |

정리하면, 이 스튜디오는 AI 기본법의 **규제 대상이라기보다 법이 요구하는 신뢰 기반(투명성·설명·사람의 관리감독·문서 보관)을 이미 구조로 갖춘 쪽**에 가깝다. 다만 아래 2가지는 설계로 못 박아 두는 것이 좋다.

1. **AI 초안 표시의 유지**: 담당자가 AI 초안을 채택해 저장하면 지금은 "사람이 입력한 값"과 구분되지 않는다. 메타데이터 필드마다 `fde:draftedBy ai`(또는 PROV-O `prov:wasGeneratedBy` → 소프트웨어 에이전트) 흔적을 남기고, 카탈로그·데이터 카드에 "AI 보조 작성 · 담당자 확정" 문구를 자동으로 붙이면 제31조제2항 쟁점이 사라진다.
2. **영향평가 우선 고려(제35조제2항)·인증 AI 우선 고려(제30조제4항)·AI 제품 우선 고려(제16조제3항, 2026.7.21 시행)**: 기관이 이 스튜디오를 "구매"하는 입장이면 조달 담당자가 확인할 항목이다. 과기정통부 고시 제2026-50호 「인공지능제품·서비스 확인 절차 운영에 관한 고시」에 따른 확인(한국인공지능진흥협회 접수, TTA 기술심사)을 받아 두면 공공 조달에서 유리하다.

## 2. 기능별 조항 대응표

| 스튜디오 기능 | 관련 조항 | 지금 구현으로 충족되는 것 | 추가하면 좋은 것 |
|---|---|---|---|
| STEP 3 AI 초안 제안 (Claude API) | 제31조제1항·제2항, 시행령 제23조 | 담당자가 버튼을 눌러야 호출되고 결과는 "초안"으로만 표시되며 저장은 사람이 한다. C 등급·전송 제외 데이터셋은 호출 자체를 막는다. 개인정보 의심 컬럼 값은 보내지 않는다 | 채택된 필드에 AI 보조 흔적 저장, 카드·카탈로그에 자동 문구. 외부 전송 내용(요약·통계)을 활동 로그에 남기는 "전송 내역" 화면 |
| STEP 7 AI 활용 시뮬레이션 | 제31조 (내부 용도 면제) | 결과가 저장되고 작성자·모델·토큰이 기록된다 | 결과 화면 상단 "생성형 AI 결과" 고정 배지 (이미 모델명 표기, 문구만 추가) |
| 발행 검수 큐 (HITL) | 제34조제1항제4호 "사람의 관리·감독", 제3조 설명 요구 | 고위험 발행은 관리자 승인, 고위험 신호 개별 확인, 자기 승인 기록, 전부 활동 로그 | 고영향 AI 는 아니므로 의무는 아니나, 기관 자체 AI 윤리기준(제27조제3항) 증빙으로 그대로 쓸 수 있다 |
| PROV-O 이력 · 활동 로그 | 제34조제1항제5호 "문서 작성·보관"(5년, 시행령 제27조) | 모든 변경·발행·AI 호출·MCP 호출이 prov:Activity 로 남는다 | 보존 기간 정책(5년) 과 로그 내보내기. 지금은 삭제 정책이 없어 사실상 영구 보존 |
| MCP 카탈로그 제공 | 제2조제7호 (기관이 에이전트에 "서비스"를 제공하는 것인가) | 키별 등급·도구·일일 상한, C 등급 비노출, 모든 호출 기록, 프롬프트 인젝션 안내 | 외부 기관·민간 에이전트에 키를 발급하는 순간 "서비스 제공"에 가까워진다. 그때는 MCP 서버 안내문(instructions)에 AI 기반 운용 사실과 이용조건을 고지하는 문구를 넣으면 제31조제1항 사전 고지에 해당한다 (지금 안내문에 추가해 두어도 비용이 없다) |
| AI 활용 이용조건 (ODRL, 표 39) | 제15조 학습용데이터 시책, 제14조 표준화 | AI 학습·결합·자동화 접근·대량 호출·재배포 허용 여부를 기계가 읽는 ODRL 로 발행 | 제15조에 따라 장관이 구축하는 "학습용데이터 통합제공시스템"과의 연계 포맷(DCAT 3 + ODRL)이 이미 맞는다. 정부 데이터 포털 연계 시 그대로 제출 가능 |
| N²SF 등급 · 전송 제외 | 제4조제2항 (국방·안보 제외), 개인정보 보호법 | C 등급은 외부 AI 에 보내지 않고 MCP 로도 열리지 않는다 | 국가안보 목적 시스템이면 애초에 이 법 적용 제외이나, 그 경우에도 C 차단은 N²SF 쪽 요구사항으로 유지 |
| 데이터 카드 (부록 4) · Croissant RAI | 제34조제1항제2호 "학습용데이터 개요 설명" | 편향·한계·보호 조치·권장/금지 사용이 `rai:` 속성으로 발행된다 | 이 데이터셋으로 **고영향 AI 를 만드는 쪽**(수요 기관)이 제34조 설명 의무를 질 때 필요한 "학습용데이터 개요"를 그대로 공급한다. 카드 머리에 "AI 기본법 제34조 학습용데이터 개요 대응" 한 줄을 넣어 수요처에 알려 주면 좋다 |

## 3. 운영 기관이 확인할 체크리스트

- [ ] 이 스튜디오가 만든 메타데이터가 대국민 포털에 게시되는가. 그렇다면 AI 보조 작성 표시를 켠다 (개발 예정 옵션).
- [ ] MCP 키를 기관 밖(민간 에이전트·타 기관)에 발급하는가. 그렇다면 MCP 안내문에 사전 고지 문구를 넣고, 키 발급 기록을 5년 보관한다.
- [ ] 기관 자체 생성형 AI 활용 지침(국정원·행안부·개보위 안내 포함)에서 외부 API 로 보낼 수 있는 정보 범위가 이 스튜디오의 "요약·통계만 전송" 원칙과 일치하는지 확인한다.
- [ ] 개인정보 보호법 관점에서 Claude API 전송이 국외 이전·처리위탁에 해당하는지 개인정보 보호책임자가 검토한다 (AI 기본법과 별개).
- [ ] 2027.1 계도기간 종료 전후의 제도개선(배포자 개념 신설, 딥페이크 표시 범위 조정) 동향을 확인한다.

## 4. 확인하지 못한 사항

시행령 제2조(국방·안보 제외)의 최종 문언, 별표 2 과태료 금액 원문, 「인공지능 안전성 확보 의무 이행방법 등에 관한 고시」·「고영향 인공지능 사업자 책무 고시」의 2026.10 현재 공포 여부, 계도기간 연장 여부는 1차 자료로 확인하지 못했다.
