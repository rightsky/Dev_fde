## 보통 (고친 것)

- `제공기관` 값이 숫자가 아니면 500 → 422 와 안내 문구
- 휴지통에 들어간 프로세스의 검수 요청을 승인할 수 있었음 → 409
- ODRL 정책에 `odrl:profile` 명시, 이용조건을 하나도 고르지 않으면 빈 정책을 만들지 않음, 표준에 없는 `odrl:uid` 제거
- `rai:knownLimitations`(가이드라인 표기, Croissant 에 없음) → `rai:dataLimitations` 로 정정. 가이드라인 대응용으로 `fde:knownLimitations` 병기. SHACL · O-06 · AI 초안 프롬프트 동반 수정
- "지난 결과입니다" 배너가 레이아웃과 단계에 이중으로 떠 있던 것을 단계 배너 하나로 합치고, 모든 배너에 [재실행] 버튼
- 점수 색 기준(75/40%)이 화면마다 달랐던 것을 `pctLevel` 하나로 통일, "부분" → "부분 충족" 라벨 통일
- 즉시 진단: 이동할 화면이 없는 항목은 목록에서 제외, 저장된 진단이 없으면 수정 안내 띠 없이 이동(빈 띠 방지), 판정 항목이 0이면 "판정 항목 없음"
- 시뮬레이션 기록 삭제 · 검수 요청 취소에 2단계 확인(4초 안에 다시 누름)
- "외부 AI 전송 제외" 변경 뒤 프로세스 · 카탈로그 질의 무효화(화면이 옛 상태로 남던 문제)
- `ConfirmButton` 에 `title` 전달, 없던 `.gap-8` 클래스 추가

## 보통 · 낮음 (v0.11 시점에 남겨 두었던 목록)

1. **AI 호출 속도 제한 없음**: 초안 제안 · 시뮬레이션 엔드포인트에 사용자별 분당 상한이 없어 비용 폭주 가능. 관리자 설정값으로 두는 것을 권함.
2. **자기 승인 정책**: 고위험 발행을 요청자 본인이 승인할 수 있음(사유 10자 + "자기 승인" 표기로 기록만 남김). 조직에 따라 금지 옵션이 필요.
3. **대용량 업로드가 이벤트 루프를 막음**: 프로파일링을 동기 실행. 수백 MB 파일이면 다른 요청이 지연됨. 백그라운드 작업화 필요.
4. **비밀번호 변경 뒤 기존 토큰 유효**: JWT 무효화 목록이 없음.
5. **MCP 401 시도가 기록되지 않음**: 유효 키 없는 요청은 서버 앞에서 막히므로 이력이 안 남음. 공격 징후 파악에는 로그가 필요.
6. **표준 세부**: `dcterms:conformsTo` · `dcterms:spatial` · `dcterms:language` 를 문자열로 넣는 곳, `dcterms:format` 에 미디어타입 대신 자유 문구, CSVW `csvw:name` 에 공백 포함 가능, Croissant `license` 가 URL 이 아닌 문자열일 때, `contentUrl` 이 로컬 경로. 발행 시 IRI 로 정규화하는 변환층이 필요.
7. **목록 API N+1**: 프로세스 목록 · 노출 계산에서 데이터셋마다 질의. 프로세스 100개 이상이면 느려짐.
8. **일일 호출 상한이 UTC 기준**: 한국 시간 09시에 초기화됨.
9. **시뮬레이션 삭제 권한**: 작성자 또는 관리자만으로 제한돼 있으나 활동 로그에는 남지 않음.
10. **접근성**: Tabs 에 `role=tablist` 와 키보드 이동, Modal 포커스 트랩, 일부 아이콘 버튼의 `aria-label`.
11. **용어 통일**: "최신 아님 / 지난 결과 / 재실행 필요"가 화면마다 섞여 있음. 한 용어로 정리 권함.
12. 기타: `PATCH current_step` 응답이 캐시를 덮어쓰는 경쟁, `justPublished` 배지가 새로고침 전까지 유지, AdminAgents 연결 안내의 빈 상태 문구, 중복 코드 정리.
